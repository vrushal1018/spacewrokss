# Ina SpaceWorks Website (Next.js + TypeScript + Tailwind CSS)

Complete multi-page website for **Ina SpaceWorks**, the interior design and build vertical of **Ina TechFM**. Built on the brand identity: the open taupe A logo, the rising outline A, the measure line with Ina TechFM blue dimension ticks, and the tagline: **Design • Build • Evolve**.

## Pages

- **`/` (Home)**: Hero with Sunrays C.H.S. Ltd entrance lobby, 3-pillar breakdown (Design, Build, Evolve), asymmetrical architectural gallery, about snapshot, and contact section.
- **`/work` (Work & Portfolio)**: Category-filtered portfolio (All, Residential & Lobbies, Corporate & Commercial, Healthcare), deep-dive case study of Sunrays C.H.S. Ltd with all 4 photography angles, scope badges, and project archive cards.
- **`/services` (Services & Methodology)**: In-depth scope for Design (space planning, 3D renders, BOQ), Build (turnkey civil, joinery, MEPF, QA), and Evolve (as-built docs, Ina TechFM facility handover, maintenance). 6-step delivery workflow.
- **`/about` (About Us)**: Origin story, the Ina TechFM facility management synergy, 4 core architectural tenets, and delivery metrics.
- **`/contact` (Contact & Consultation)**: Interactive project enquiry brief form, direct coordinates (Thane West office, direct phone, email, hours), and comprehensive FAQ accordion.

## Brand Tokens & Color Palette

- `--ink`: `#1B1F24` (Primary charcoal)
- `--slate`: `#5C6670` (Secondary muted architectural text)
- `--body`: `#3E464F` (Reading copy)
- `--taupe`: `#878787` (Roof open A outline)
- `--stone`: `#F3F1EC` (Warm architectural paper background)
- `--white`: `#FFFFFF` (Card surfaces and clean section backgrounds)
- `--rule`: `#D9D4CA` (Divider lines and borders)
- `--blue`: `#2495D3` (Ina TechFM accent blue: dots, ticks, highlights)
- `--tab`: `#1B7DB5` (Ina TechFM tab blue: badges, primary buttons, active links)

## Run Locally

```bash
cd ina-spaceworks-web
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm start          # run production server
```
